# Summarise a fictional log

Save three source files in a NEW empty lesson folder.

    python make_sample.py
    python logsummary.py sample/app.log
    python -m unittest -v

Two Windows and two Ubuntu full replays run exact visible source versions. Final 32 small fixture tests pass (Unix pipe skips on Windows); symlink creation can skip where unavailable. First Windows stdout is displayed, not normalized/mixed. Pair differences are test time and the unique temporary path in the deliberately crashing prototype traceback.
The initial naive prototype deliberately crashes on the fictional sample's unexpected line and is labeled sample-only. It is replaced by the full final reader, which refuses input/ancestor symbolic links/reparse points, hardlinks, special files and traversal before opening. Metadata/open errors return 2 with readable fallback error text. Setup also refuses linked parents/traversal and any existing sample path; no reset or deletion.
Original final parsing, timestamp/level rules, UTF-8 replacement decoding, counts and excerpts are unchanged. Malformed lines remain counted/listed and keep prior exit 0, not a clean-log or diagnosis certificate. No new encoding/parser/error-analysis rule. Logs can reveal private names, tokens and error details; practice uses fictional lines only.
The checker has no write/move/delete/network code. Unreadable-line storage can grow with the file, and chunk/stream processing is not a resource limit. Stop editors/sync; no atomic snapshot or hostile-race defense. Tests are small fixtures, not real service diagnosis or proof on all filesystems. No desktop Windows/macOS recording. Recorder removes only its own temporary fixture folder. Decisions and feedback are teaching text, not recorded output.
